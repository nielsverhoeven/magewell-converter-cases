# Pro Convert for NDI to HDMI

**Priority model for this project.**

## Identity
- SKU: 641000000 (part 64100)
- Product page: https://www.magewell.com/products/pro-convert-for-ndi-to-hdmi
- Datasheet: https://www.magewell.com/static/tech-specs/Pro_Convert/ProConvertforNDI_to_HDMI.pdf
- Manual: https://www.magewell.com/files/documents/User_Manual/ProConvert_Decoder-UserManual_en_US.pdf
- QSG: https://www.magewell.com/files/documents/Quick%20Start%20Guide%20for%20Pro%20Convert%20Decoders.pdf

## Type / interfaces
NDI decoder — HDMI output up to 4096×2160p60 (decode 2Kp60); USB 3.0 Type-A host (keyboard/mouse).

## Physical
- Housing family: [Compact/TX](../housing-families.md#b-compacttx-1009--602--233-mm)
- Dimensions: 100.9 × 60.2 × 23.3 mm
- Weight: unknown

## Port layout
- Face A: HDMI OUT → decoding LED → USB HOST (Type-A)
- Face B: USB 2.0 Type-B "+5V" → Power LED → RJ45 "NDI+PoE"
- Top, near Face A: SD-card slot (non-functional) + 1/4"-20 hole
- Top, near Face B: 16-position rotary switch, MENU button, SELECT button
- No Kensington slot, no physical reset button

## Power
- PoE: IEEE 802.3af
- DC: 5 V via USB-B, ~1.1 A; bundled adapter 5 V/2.1 A
- Max power: ~5 W

## Thermal
- Operating temperature: 0–40 °C
- Fan: no

## Mounting
- 1/4"-20 threaded hole; L-bracket #92240 in box; Fishtail bracket STL also compatible
- ACC10012 "Pro Convert TX Mounting Kit" compatible

## Other notes
Controls: MENU + SELECT buttons + 16-position rotary switch. FCC Part 15, 2-year warranty. A
separate "Module" variant exists for the Modator 2U rack chassis (different form factor, not this
boxed unit — see `../accessories.md`).
